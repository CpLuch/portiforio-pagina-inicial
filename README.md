# Portfólio Pessoal — Ricardo Henrique

> **Projeto acadêmico da disciplina de Desenvolvimento Web**, desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas.

Este portfólio nasceu como uma atividade da faculdade, mas foi construído com um objetivo pessoal: criar um site que realmente representasse minha trajetória, meus interesses e os projetos que venho desenvolvendo.

O site reúne trabalhos de programação, banco de dados e prototipagem, além de um espaço dedicado à fotografia, às viagens e a outros interesses pessoais. Cada página foi pensada para manter uma identidade visual consistente e oferecer uma navegação simples em computadores e celulares.

## 🌐 Acesse o site

**Endereço planejado para publicação no GitHub Pages:** https://cpluch.github.io/

> O link funcionará depois que o repositório `CpLuch.github.io` estiver publicado e o GitHub Pages estiver ativado.

Aplicar na prática os conhecimentos da disciplina de **Desenvolvimento Web**, especialmente:

- Estruturação de páginas com HTML5;
- Estilização e responsividade com CSS3;
- Interatividade com JavaScript;
- Organização de arquivos, navegação e integração de conteúdo;

## ▶️ Como executar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Abra o arquivo `index.html` com um servidor local, como a extensão **Live Server**, ou diretamente pelo navegador para conferir as páginas estáticas.
4. Navegue pelo menu para conhecer as outras seções.

Alguns recursos incorporados, como mapas e vídeos externos, precisam de conexão com a internet.
